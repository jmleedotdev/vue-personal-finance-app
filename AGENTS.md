## Agent skills

### Issue tracker

Issues live as local Markdown files under `.scratch/<feature>/`. See `.agent-docs/issue-tracker.md` when creating, fetching, or updating issues.

### Triage labels

Use the default five-role triage vocabulary. See `.agent-docs/triage-labels.md` when assigning triage status.

### Domain docs

Single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring the codebase, read `.agent-docs/domain.md`.

### UI implementation and review

Before any UI implementation or review, read `.agent-docs/design-system.md` for private Figma references and cached designs, and `CODING_STANDARDS.md` for shared controls, theme tokens, and utility-first styling. These foundations apply across all features.
